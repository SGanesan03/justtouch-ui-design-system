# JustTouch UI — React + Vite + TypeScript Design System

A complete, end-to-end React UI component library and design system explorer built with **React 18**, **Vite**, **TypeScript**, **Tailwind CSS**, and **Lucide Icons**.

## Features Included
- **Landing Overview:** Hero section, CLI quick-copy installer, interactive workspace stats, and architecture highlights.
- **8-Category Docs & Component Explorer:**
  1. **Documentation:** Overview directory (visual blueprint cards), Introduction, Installation, Colors & Tokens, Typography.
  2. **Resources:** Searchable Icon gallery with 1-click JSX copy, Brand Logo marks, Figma UI Kit specs.
  3. **Base components:** Buttons, Badges, Avatars, Inputs & Forms, Loading indicators, Progress steps.
  4. **Application UI components:** Header navigations, Metrics & KPIs, Charts (Line/Bar/Donut), Data tables, Modals, Notifications, Paginations, Gradient/Image pickers, Messaging.
  5. **Application UI examples:** Full SaaS Dashboards & Settings pages.
  6. **Shared page examples:** Login/Sign up, Pricing pages with billing switcher, 404 & Empty states.
  7. **Marketing components:** Hero sections, Feature grids, Inline CTAs, Testimonials, FAQ accordions, Footers.
  8. **Marketing examples:** Landing pages, About pages, Blog, Contact, and Legal pages.
- **Interactive Component Sandbox:** Every component preview supports Desktop/Tablet/Mobile viewport switching, independent Light/Dark mode toggling, and 1-click TSX code copy.

## Quick Start

```bash
npm install
npm run dev
```
